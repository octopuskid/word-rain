# Word Rain 0.0.1 — original prototype

This is the very first Word Rain HTML game, recovered from the original deployment archive `word-rain.tar.gz` (`dist/index.html`). The label 0.0.1 is assigned retrospectively for this historical release.

The HTML is preserved byte for byte, with no gameplay changes, bug fixes or modern features added. Its original automatic letter changes, fixed five-letter word sequence, score/best display, three-heart bomb mechanic, touch/keyboard controls and pause behavior are retained. It contains no music, shields, difficulty selector or Android wrapper.

Download `word-rain-0.0.1.html` and open it in a modern browser, or extract the ZIP and open `index.html`. Browser support can affect touch/canvas/storage behavior. The original local high-score key is `word-rain-best`; it does not use the current Android records key.

Historical source branch: `archive/0.0.1`. The current game remains on `main`; this archive does not replace the modern demo or latest release.
